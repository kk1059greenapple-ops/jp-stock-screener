# 日本株 上昇期待度スクリーナー

東証上場銘柄(楽天証券で取扱いのある国内株を想定)を対象に、指定した価格帯の銘柄について
直近ニュースを無料ソースから検索し、発信元の信頼度・見出しの煽り表現に加えて、移動平均線・RSI・
日経平均との相対強さなど過去の値動きのみに基づく客観的なテクニカル指標も組み合わせて
「上昇期待度(%)」を機械的に算出して一覧表示するツールです。

**これは投資助言ではありません。** あくまでニュース見出しをもとにした参考スコアであり、将来の株価を
保証するものではありません。売買前には必ずご自身で一次情報を確認し、楽天証券で実際に取扱いがあるかを
確認してください(各銘柄に楽天証券の検索ページへの直リンクがあります)。

## 仕組み

1. `scripts/update_universe.py` — JPX公式の東証上場銘柄一覧(`data_j.xlsx`、無料)から国内株式の
   銘柄コード・銘柄名一覧を取得する。
2. `scripts/fetch_prices.py` — [yfinance](https://github.com/ranaroussi/yfinance)(無料・APIキー不要)で
   各銘柄の直近株価を取得し、指定した価格帯(`--min-price` / `--max-price`)で絞り込む。
3. `scripts/technical_factors.py` — yfinance(無料、価格データのみ)で直近1年の値動きを取得して
   ニュースに依存しない客観的な指標を算出し、[株探(kabutan.jp)](https://kabutan.jp/)の
   ログイン不要の公開ページからPER・PBR・決算発表予定日を取得する。特定の「秘密のノウハウ」では
   なく、ファクター投資(バリュー・モメンタム)や出来高分析、日本市場特有の制度として公表・研究
   されている一般的な手法を、公式・公開データで計算できる範囲に落とし込んでいる。
   - 25日/75日移動平均線によるトレンド判定(上昇/下降/中立)
   - RSI(14日) — 売られすぎ/買われすぎの判定
   - 52週レンジ内の位置(年初来高値・安値からの乖離)
   - 1ヶ月/3ヶ月騰落率、日経平均(^N225)との相対強さ(モメンタムファクター)
   - **出来高分析**: 直近出来高が20日平均の何倍かを見て、価格の動きが出来高を伴っているかを判定する
     (「出来高は価格に先行する」という、プロのトレーダーがブレイクアウトの真偽を見極める基本原則)
   - **同業種内のPER相対評価**: PERの適正水準は業種によって大きく異なるため、絶対水準ではなく
     東証33業種区分内での相対順位(バリューファクター)で割安・割高を判定する(同業種3銘柄未満の
     場合はノイズが大きいため反映しない)
   - **PBR1倍割れ**: 東証が2023年から上場企業に資本効率・株価を意識した経営改善を要請しているという
     公表済みの制度的事実に基づき、PBR1倍割れ銘柄には改善期待のテーマ性があるとして加点する
   - **決算発表接近の注意喚起**: 決算発表が近い銘柄は株価変動リスクが高まるため、方向性は判定せず
     「📅決算間近」として警告表示のみ行う
   - PER・PBR・配当利回りは株探の表示値をそのまま使用(参考情報)

   なお、PER/PBR/決算発表予定日はyfinanceではなく株探から取得している。yfinanceの銘柄詳細API
   (quoteSummary)はクラム認証が必要で、GitHub Actionsのようなクラウド実行環境の共有IPからの
   アクセスをYahoo Finance側がブロックすることを実際に確認したため(価格データ自体のchart APIは
   クラム不要でブロックされない)。
4. `scripts/fetch_news_and_score.py` — 絞り込んだ銘柄についてGoogleニュースRSS(無料)で直近10日分の
   関連ニュースを検索し、
   - 発信元の信頼度(主要通信社・大手紙 > 専門メディア > 集約サイト > 発信元不明)
   - 見出しの煽り表現(「絶対」「確実に急騰」などのクリックベイト検知)
   - 複数の信頼できる情報源による裏付けの有無
   - 直近の値動き(前日比)
   - `technical_factors.py` で算出したテクニカルスコア(取引所の実際の値動きに基づく客観データのため、
     ニュース解析より裏付けが確実な要素として加点)

   を組み合わせて「上昇期待度(%)」と「信頼度(高/中/低、ニュースの発信元信頼度ベース)」を算出し、
   `data/scores.json` に保存する。信頼度が低く煽り表現を含むニュースには `fake_news_risk` フラグを立てる。
5. `docs/index.html` — `data/scores.json` を読み込んで表示する、スマホ対応の静的ページ。
   GitHub Pages で公開すればスマホからも閲覧できる。各銘柄の行を開くとテクニカル・ファンダメンタルズの
   詳細と判断根拠、関連ニュース一覧が表示される。

## ローカルでの実行方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 例: 株価1000円〜3000円の銘柄を検索
python scripts/run_all.py --min-price 1000 --max-price 3000
```

実行後、`data/scores.json` が更新されます。`docs/index.html` をブラウザで直接開くとローカルの
`file://` 制約でJSON読み込みがブロックされる場合があるので、確認は以下のように簡易サーバー経由にしてください。

```bash
cp data/*.json docs/data/
cd docs && python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHubで公開してスマホから見る

1. このフォルダの内容をGitHubの新規リポジトリにpushする。
2. リポジトリの Settings → Pages → Source で「Deploy from a branch」→ ブランチ `main` / フォルダ `/docs` を選択。
   数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになる(スマホからもOK)。
3. `.github/workflows/update.yml` が平日16:30(市場終了後)に自動実行され、株価0〜100,000円の範囲で
   値動きの大きい上位150銘柄を自動スキャンして結果をコミットする。
4. **価格帯を指定して都度検索したい場合**: GitHubのActionsタブ(スマホならGitHubアプリでも可)から
   「Update stock scores」→「Run workflow」を選び、最低株価・最高株価を入力して実行する。
   数分後にページを再読み込みすると、その価格帯の最新結果が反映される。

## 既知の制約

- 「上昇期待度」はニュース見出しのキーワード解析とテクニカル指標の組み合わせによる簡易指標。決算の進捗、
  需給、マクロ経済など、実際の株価変動要因をすべて反映しているわけではない。
- テクニカル指標(移動平均・RSI・日経平均比)は取引所の実際の値動きに基づく客観データだが、過去の値動きが
  将来を保証するものではない(トレンドフォロー型の指標は急な反転を捉えられない)。
- PER・PBR・配当利回りは参考情報。割安だからといって株価が上昇するとは限らない。
- 同業種内のPER相対評価は、スクリーニング対象として同時に抽出された銘柄群の中での相対比較であり、
  市場全体における業種内の正式なランキングではない(価格帯の絞り込み方によって結果が変わりうる)。
- PER/PBR/決算発表予定日は株探のページ構造に依存したスクレイピングのため、サイト側のHTML変更で
  取得できなくなる可能性がある(その場合は該当項目を表示しないだけで、処理全体は止まらない)。
- 銘柄によってはPER/PBRがそもそも算出不能(赤字企業など)で、株探側も「-」表示のため取得できない
  ことがある。その場合は該当項目を表示しない(無理に埋め合わせない)。
- 楽天証券での取扱い確認は自動化していない(個別銘柄ページはログインが必要なため)。各行の「確認」リンクから
  手動で確認すること。
- ニュース検索はGoogleニュースRSSに依存しており、検索結果の網羅性はGoogle側の仕様に左右される。
- 1回の実行でニュース・テクニカルを深掘りする銘柄数は既定で150件(`--limit`で変更可)。価格帯を絞るほど、
  より多くの該当銘柄を深掘りできる。また1年分の価格履歴取得とPER等の取得が加わった分、以前より実行時間が
  伸びている。
